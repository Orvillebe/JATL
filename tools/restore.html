Backup terugzetten

Deze pagina maakt de SQL om een backup terug te zetten. Ze praat zelf niet met de database en verstuurt niets. Jij plakt de SQL in Supabase.

1. De backup die terug moet

Het bestand jatl-backup-….json met de toestand waarnaar je terug wil.

2. Een backup van nu

Download in JATL bij Beheer eerst een verse backup en zet die hier. Zo zie je wat je zou verliezen, en heb je meteen een weg terug als het terugzetten niet is wat je wou.

3. Wat er verandert

4. Uitvoeren in Supabase

  1. Open je project in Supabase, ga naar SQL Editor en kies New query.
  2. Plak de SQL en klik op Run. Supabase waarschuwt voor een destructieve actie: bevestig.
  3. Onderaan verschijnt een verslag met de aantallen. Faalt er iets, dan zie je een fout en is er niets veranderd.
  4. Download daarna in JATL een nieuwe backup en vergelijk die met de backup uit stap 1 in compare.html. Elke tabel hoort "gelijk" te tonen.
